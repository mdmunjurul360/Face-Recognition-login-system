# Face Recognition Login System

> ⚠️ Learning Project – Educational Purpose Only

## Overview

This project is a simple face recognition login system built for learning purposes using the Face++ API. 

The objective of this project was to understand:

- Face detection
- Face comparison
- API integration
- Webcam image capture
- Basic Express.js backend

This project was created as a study project and is **NOT intended for production authentication**.

---

## Features

- Webcam image capture
- Face detection
- Face comparison using Face++ API
- Simple Express.js backend
- Browser-based interface

---

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Face++ API

---

## Installation

```bash
npm install
```

Create your environment file.

```
cp .env.example .env
```

Add your own Face++ API credentials.

Run the server.

```bash
node server.js
```

---

## Environment Variables

```
API_KEY=your_api_key
API_SECRET=your_api_secret
```

---

## Security Notice

This repository does **not** contain real API credentials.

All sensitive configuration has been removed.

Use your own Face++ API credentials locally.
